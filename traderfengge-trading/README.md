# traderfengge-trading

把 YouTube 财经频道「比特币峰哥」（@Traderfengge）的方法论蒸馏成可执行的趋势跟随型合约交易纪律检查技能。

## 什么时候用

当用户说类似下面这些话时，加载本技能：
- "用峰哥的方法看一下 BTC"
- "按峰哥的框架检查一下现在的行情"
- "traderfengge check" / "峰哥视角"

## 它是什么

- Workflow-only 技能：`SKILL.md` 给出研判流程（定趋势 → 定结构 → 定三要素 → 纪律检查 → 宏观过滤）与输出契约。
- `references/methodology.md`：方法论 5 条、策略纪律、本框架没有的东西、证据局限。
- `references/videos.md`：13 期代表视频证据链。

## 它不是什么

- 不是纯观察型框架：峰哥是带单型交易者，输出的是"入场/止损/止盈"三要素单子，不只是方向判断（想看不带单的纯 K 线视角用 `cakebaba-trading`）。
- 不是宏观/资金流框架：US10Y、恐贪指数、MVRV、ETF 资金流不在其方法论内（想看资金流用 `distillP-btc-analysis`）。

## 维护

- 阈值带时间戳：80,000 / 85,000 / 87,100 / 90,000 是 2026-09 语境下的点位示例，不是通用常量。
- 其"5 连胜""盈利 XXX 点"等战绩为自报，引用时必须注明未经第三方验证。
- 若频道观点发生转向，更新 `references/methodology.md` 并同步时间戳。
