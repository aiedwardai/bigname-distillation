# 比特币峰哥交易方法论

## Purpose
把 YouTube 财经频道「比特币峰哥」（@Traderfengge，2026-01 至 2026-09 约 15 期节目 + Telegram 公开策略帖蒸馏）的趋势跟随型合约交易纪律变成可执行的研判流程。核心是：**跟随行情走，而不是预测行情；下跌不言底、上涨不摸顶；每单必有入场/止损/止盈三要素**。

完整方法论、策略纪律与证据来源见 `references/methodology.md`；代表视频清单见 `references/videos.md`。

## Workflow
1. **定趋势**：当前是上涨、下跌还是震荡？只做跟随，不做预测——无反转信号就不猜顶（上涨市）、不抄底（下跌市）。
2. **定结构**：用形态（双顶、洗盘、箱体顶/底）定义操作区域，再用斐波那契 0.5–0.618 回测划分第一/第二买区与核心支撑。"读懂结构而不是瞎猜"。
3. **定三要素**：把判断翻译成可执行的单子——入场（限价挂入、不追单）、止损（防守点）、止盈（目标位）。反弹默认定性为洗盘/诱多，直到结构确认。
4. **纪律检查**：是否重仓？是否在侥幸？仓位是否低倍？到目标位是否该走（并提示清算风险）？
5. **宏观过滤**：利空兑现即视为 price-in，不单独用宏观翻转立场。他是纯技术派。

## Output Contract
- 趋势结论：当前趋势方向、反转信号有无
- 结构与买区：形态、箱体、斐波那契买区、核心支撑/防守点
- 三要素单子：入场 / 止损 / 止盈，全部条件式表述（"若…则…"）
- 纪律检查：重仓/侥幸/杠杆倍数/出场纪律
- 标注：数据日期、哪些结论来自他自报战绩（未经验证）、本次未覆盖的指标

## Operating Rules
1. 本框架是合约交易纪律框架，不是长期配置框架；但他的 ETH"现货逢低定投"主张可单独引用。
2. 只做条件式表述与趋势跟随，不做确定性预测（"无反转信号就顺势"而不是"会涨到 X"）。
3. 下跌不言底：下跌趋势中不猜底、不抄底；上涨不摸顶：无反转信号不逆势做空。
4. 阈值带时间戳：80,000 核心支撑 / 85,000 洗盘结束确认 / 87,100 出局位 / 90,000 上方目标是 2026-09 语境下的点位示例，不是通用常量。
5. 他自称的道氏/波浪/谐波/江恩四件套在可验证材料中没有实际用法，不要脑补进分析。
6. US10Y、美元指数、恐贪指数、MVRV、ETF 资金流不在他的方法论内，不要硬套（想看资金流用 `distillP-btc-analysis`）。
7. 引用其"5 连胜""盈利 XXX 点"等战绩时必须注明是他自报、未经第三方验证。
8. 输出中文；所有内容不构成投资建议。
