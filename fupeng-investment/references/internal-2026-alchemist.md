## 一、投资思维总纲：六项

总纲页（未标注日期，列于文档开篇）：

1. **周期思维** 2. **概率—赔率** 3. **趋势思维** 4. **杠杆思维** 5. **复利思维** 6. **套利思维**

这是其全部投资论述的上层框架。用法：任何决策先问属于哪一项思维——周期位置对不对、概率赔率划不划算、趋势方向顺不顺、杠杆用没用、复利有没有被破坏、有没有套利空间。

## 二、四象限投资决策矩阵（2026-05-13）

按**流动性、资本支出（CapEx）、估值**三维组合：

- 流动性宽松 + CapEx 扩张 + 估值低：**最优组合**
- 流动性宽松 + CapEx 扩张 + 估值高：持有，但要配置保险
- 流动性收紧 + CapEx 收缩 + 估值高：**最差组合**，回避/现金/保险
- 流动性紧张 + CapEx 收缩 + 估值低：困境反转候选，等待流动性和 CapEx 的拐点

原资料带有"强烈买入"等操作措辞，蒸馏为**框架检查**：先定位当前处于哪个象限，再决定"持有/加保险/回避/等拐点"，不输出确定性交易指令。

## 三、事件交易：预期与现实分离（2026-04-15、04-22、04-29）

核心句：**"通和不通是现实，谈和不谈是预期。"**（关税/谈判事件复盘）

- 情绪冲击期：波动率急升、价格剧烈波动；
- 情绪消退期：波动率下降，但绝对价格不一定回去；
- 物理伤害显现期：低波动率、价格缓慢上行——表面平静，但供应冲击开始进入现实。
- 市场可以交易"将和谈"，但炼厂库存、运输时间、真实供给不会因预期立刻恢复。

用法：事件发生后先判断处于三阶段中的哪一段；**预期和现实分两条轨道看**，不要用预期的修复去论证现实的修复。

## 四、传导分析纪律：时滞与内部结构（2026-05-28）

不要把资产传导理解成即时数学公式。两类典型错误：

1. A 变量变化后，第二天没看到 B 就认为传导失效——要"让子弹飞一会"，理解**传导时滞**；
2. 只看资产总量、不看内部结构——例如只看利率不看曲线结构、只看指数不看成分股结构。

分析规则：先画传导链 → 明确中间介质 → 标注预期时滞 → 检查内部结构，而非只看 headline 指标。

## 五、VIX 与 VIXEQ：指数稳定可能是假象（2026-06-04、06-20）

- 极致缩圈、权重高度集中时，少数巨头压低指数 VIX；
- **VIXEQ** 更能反映标普成分股整体的隐含波动率；
- VIX 与 VIXEQ 差距扩大，说明指数由少数公司支撑，其他股票的波动率已经抬升；
- 在这种结构下，用 VIXEQ 观察 BTC/ETH 与权益市场流动性联动，可能比单看 VIX 更有效；
- "表面稳定、内在脆弱"；虹吸尽头可能突然反向。

## 七、AI 产业生命周期细化：上中下游不同步（2026-03-02、03-03、03-05、05-07、06-24）

- 上游硬件/算力基建：英伟达、台积电、三星、海力士、CPO/HBM 等；
- 中游软件：正在经历 AI 的"创造性破坏"，传统软件估值先被杀，再等待重构；
- 下游应用：尚未出现足以证明基建投资回报的里程碑；
- 产业周期不是同步的：英伟达领先，台积电/海力士等上游配套慢半拍，软件端又处另一阶段；
- **超额收益往往来自产业重构阶段**，而不是已经进入确定性成熟期的部分；
- "路修好了，有没有车跑"是 AI 下半场的核心问题（2026-06-24 等多次出现）；
- 恒生科技被定义为"中国互联网时代延续 + AI 中游软件平台"，以此解释其与韩、日、台 AI 硬件市场的分化；
- 区分结构性高毛利护城河与原材料/周期性高毛利（与公开 skill 的"结构性 vs 周期性高毛利"呼应，此处补产业链上下游定位）。

## 八、"开船 + 看船底"综合决策四维度（2026-05-07）

四个综合维度，缺一不可：

1. 产业方向是否正确
2. 当前估值是否便宜
3. 流动性是否充足
4. 有哪些外部不确定性

"开船"指跟随产业方向；"看船底"指在高估值、流动性收紧、外部风险上升时同步配保险。与公开 skill 的"行船多看船底"口诀为同一体系，此处补全四维度检查表。

## 九、居民储蓄迁移与新旧生产关系（2026-05-19）

- 居民贷款增速转负，短贷、长贷均处净偿还，旧房地产/房贷关系仍在去杠杆；
- 储蓄增速高于信贷，居民倾向储蓄而非借贷；
- 部分储蓄转为非银机构存款，流向股市；
- 资金一端流向高股息红利，一端流向新质生产力科技；
- 旧生产关系资产受去杠杆制约；新生产力资产短期高收益但中期要验证未来增长，存在泡沫风险。

用法：中国资产配置中"哑铃结构"的资金面依据——一端红利（确定性），一端新质生产力（赔率）。

## 十、波动率是保险，不是长期持有标的（2025-12-13）

- 波动率本质是"对风险的保险"，不是应长期持有的方向性资产；
- 高估值 + 波动率中枢上升 = 稳定性下降；
- **保险成本的变化，可作为市场从"高确定性"转向"不确定性上升"的信号**。

## 十一、战争不做交易核心（2026-03-01、03-10）

- 战争信息高度不对称，交易者获取的是多手信息；
- 现代战争节奏快，斩首、和谈、内部变化都不可稳定预测；
- 战争可以作为风险和波动率背景，但不应成为确定性交易主线；
- 更适合等待真实趋势和物理影响出现后再做判断。

## 十二、"战争金属"与政策驱动（2026-01-01、01-15、01-17、02-02）

- 战略金属价格的异常波动可能主要由战争预期、国家储备、关税和供应链安全驱动，不一定来自产业需求；
- 政策是波动率来源，而且不可预测；
- 需区分：战略库存转移、现货库存、加工费、远期结构、真实终端需求；
- 与公开 skill"价格不是结果，而是激励机制的起点"为同一商品框架，此处补"政策驱动型波动"的识别清单。

## 十四、BTC = 算力价格论（2026-09-26、09-28）

- BTC 的生产方式完全是算力流程，又不像产业链有最终应用，逐步变成价值符号——**算力的价格**；
- 不像黄金是单纯的信用对冲和信仰价值，BTC 自身有着和算力密切相关的生产机制，可理解为**算力价格的金融衍生品**；
- 决定因素：算力供需与成本——短缺上升、过剩下降、成本高上升、成本低下降；
- 产业阶段推演：算力昂贵 → 刺激上游硬件投入与 CapEx → 算力价格与硬件投资正反馈 → 供给预期加大 → 若应用端需求未跟上，供需曲线变化冲击算力价格；BTC 与 NVDA 的"劈叉"正在反映这一阶段；
- 矿企（RIOTS 例）股价类似 BTC 波动率：高位算力价格低波时矿企稳定，波动率放大若对应算力价格下跌，则可能是矿业公司倒闭潮。

## 十五、BTC 与美债收益率的三阶段相关性（2026-09-07）

- 2020–2021 年底：正相关——BTC 与 AI 产业同处早期估值阶段（分子逻辑）；
- 2021 年底–2022 年底：利率快速抬高进入"利率杀估值"阶段，负相关（分母逻辑）；
- 2023 年底至今：**正相关回归**，分子因素（AI 产业）影响大于分母因素；US10Y 走三年收敛三角形，BTC 走有斜率向上的收敛三角形——"AI 估值的抬高对应的就是 BTC 的斜率重心"，即 BTC 变成 AI 应用综合指数的又一证据。

## 十六、AI CapEx 循环：铁索连船（2026-09-29）

- 英伟达–OpenAI–甲骨文三角：NV 向 OpenAI 投资最高 1000 亿美元，OpenAI 分五年向甲骨文采购 3000 亿美元算力，甲骨文用 400 亿美元向 NV 买卡——"你投我，我投你，你买我，我买它"的现金流相互循环；
- 从商业角度是战略联盟（构建技术竞争优势、形成实质联盟垄断、规避反垄断嫌疑）；
- **从金融角度是一种杠杆行为**："曹操以铁索连环船增强稳定性，却面临火烧连船的隐患"；类比中国房地产：恒大绑定上游建筑/建材公司，现金流放缓即被困住；
- 淘金比喻：NV 是卖铲子的，OpenAI 是金矿，Oracle 是采矿队；卖铲子利润丰厚但现金过剩时不应盲目扩产能，而应把资金用于支持客户购买自身设备、扩大需求；
- 关键判断切换：二级市场投资节奏的关键不是"AI 产业链未来大有所为"（已确定的论调），而是**华尔街主流对 CapEx 的态度**——继续高歌猛进 / 关注降本增效（正面）/ 关注需求应用端能否跟上（担忧）；
- 唯一需要紧盯的：**以 OpenAI 为代表的应用端增长速度**；需求被证明 → 连环铁船形成巨大需求循环；需求被证伪 → 火烧连营放大产业链整体波动率。

## 十七、英特尔事件：国家主义视角的事件分析法（2026-09-18、09-20）

- 事件：NV 50 亿美元 + 软银 20 亿美元 + 美国政府 89 亿美元（芯片法案补贴转股权）入股英特尔，均只买普通股、不要治理权；
- 分析方法：**看交易结构反推动机**——反常的交易结构（巨资买普通股、不要席位）必有结构外原因；
  - 软银：为搞好与特朗普政府关系（减少投资审查阻力）、为参与"星门计划"铺路；
  - NV：有把柄在特朗普手里（H20 对华出口 15% 分成、芯片法案层层加码），"输血"换继续做中国生意；
  - 美国政府：保住唯一本土高端芯片制造能力（"保住英特尔就是保住美国芯片制造的核心"），应对台积电地缘风险；
- 上升到的方法论：AI 产业链崛起于逆全球化背景，必带强国家主义意识形态；各国以国家安全为名绑定制造体系在本土；**政府入股企业 = 国家主义产业政策的典型动作**（对应中国"一切和该战略相关的产业和公司都将加速上市和加大财政补贴"）；
- 风险提示：英特尔若 2–3 年内不能用这笔钱重振制造优势，合作者会从核心专利、股价操作、份额争夺上把损失拿回去。

## 十八、右翼化框架与利率曲线陡峭化（2026-10-05、10-08 深度文章）

> 本节偏宏观，`fupeng-macro` skill 同步收录；此处保留投资含义。

- 全球加速"右"转：右翼价值观聚焦本国集体利益——反移民、增加本国补贴、调整投资方向、关税平衡失衡；
- 右翼政策的市场传导：
  - 短期：不确定性上升 → 货币政策保持相对宽松；财政刺激推高赤字，汇率承压，股市受益于贬值+刺激预期；
  - 中期：反移民 → 劳动力短缺 → 工资与通胀预期上升；长端利率攀升，企业融资成本上升；
  - 长期：若技术进步与产业再分工顺利，潜在增长率提升，汇率与资产价格受益；但政策不确定性始终是波动源；
- **利率曲线必然陡峭化**：右翼财政刺激+反移民推高远端通胀中枢（长端上），而转型期打破既有利益结构、短期经济预期下滑、央行基于审慎难以跟随（短端承压）；
- 政府债务与信用风险的顶峰：左翼化长期把债务和杠杆转移到政府身上；右翼化初期市场担忧政客能力不足、政府信用受质疑 → 黄金等避险资产疯狂上涨；类比 1970 年代中期（黄金脱钩、石油美元挂钩、全要素生产率回升后秩序重塑完成）；
- 日本特殊性：高债务（债务/GDP 超 250%）背后是"全球化套利的资产负债表"（日元负债 → 海外资产）；右翼化+对内投资增加将逆转它（日元负债 → 日元资产）；YCC 长端退出不可避免；巴菲特借贷日元投资日本商社即押注这一逻辑；
- 汇率"先贬后升"路径：右翼化经济体普遍先因财政扩张+低利率承压贬值，远期若技术进步与产业再分工兑现则升值（配套案例：欧元看跌期权，2026-10-08）。

## 十九、稳定币论（"付鹏说2"，2025-08-29 视频整理稿）

> 偏宏观货币秩序，`fupeng-macro` skill 同步收录；此处保留资产含义。

- 本质：**高效的清算与支付工具，而非货币或储蓄工具**；
- 三个常见误区：① 稳定币不能为持有人带来收益（利差归发行机构）；② 不能大幅增加美债需求（对应资金多原本就在传统体系内，增量仅来自暗网资金合规化，规模有限）；③ 不等同于货币（货币三功能：价值储藏、价值尺度、流通支付；稳定币仅具支付清算功能，无储蓄与派生信用能力）；
- 深层框架：1951 年后美国形成"白宫—财政部—美债"与"独立美联储—商业银行体系"两条平行制衡链；特朗普政府试图逆转分权、重新集中权力；稳定币 = 为财政部创设的**准发钞渠道**，财政权与货币权首次在同一维度耦合；
