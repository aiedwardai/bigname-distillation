# 付鹏投资方法论 Skill

## Purpose

把付鹏的投资认知、策略与方法论变成一套可执行的纪律检查表。投资决策前先过一遍：认知层（他怎么想）、策略层（他怎么做配置）、方法层（他看什么信号）。全文蒸馏见 `references/investment.md`，内部资料（《年度专栏 文档资料》，炼药师·炼金阁）独立蒸馏见 `references/internal-2026-alchemist.md`，一句话清单见 `references/checklist.md`。

## Workflow

按三层顺序做检查，不要跳步：

1. **认知检查（为什么这样做）**：读 `references/investment.md` 第一部分。用"配置思维 vs 赚钱思维"、"确定性 vs 收益率"校准目标；用"股价交易的是预期、基本面滞后"、"确定性滋生贪婪→加杠杆"、"反身性"校准市场观；用投资思维六项、传导时滞纪律做补充；用他明确反对的东西（绝对化判断、信仰式持有、把价值投资简化为长期持有）排除错误选项。
2. **策略匹配（做什么配置）**：读第二部分。按投资者分群（小登/中登/老登）定风险预算；用哑铃型配置定结构（本金不动、只用利息冒险）；用四象限矩阵（流动性×CapEx×估值）定位当前环境；用缩圈逻辑定方向（流动性收紧时资金向核心确定性资产集中）；用"脚踏两只船"定对冲（左手人类有未来的资产、右手人类可能没未来的资产）；事件驱动时用预期—现实分离三阶段判断位置。
3. **方法落地（看什么信号）**：读第三部分。用五层分析框架定权重（产业/流动性/市场层优先，经济数据淡化）；用流动性 P/Q×G 与波动率指标（VIX1-3 价差、VIXEQ、GVZ、期权 skew、SRF）做风险预警；用产业生命周期（前段波动、后段确定；上中下游不同步）定择时位置；用"开船+看船底"四维度与"行船多看船底"定风控（低波动+高估值时频繁买短期保险）。

## Output Contract

输出一份投资纪律检查，格式：

- **结论先行**：一句话——这笔投资/这次调仓在付鹏框架下是否成立。
- **认知层**：目标校准（配置思维还是赚钱思维）、市场观（预期 vs 基本面、确定性与杠杆）。
- **策略层**：分群定位、哑铃结构、缩圈方向、是否需要对冲。
- **方法层**：当前流动性位置、波动率信号、产业生命周期位置、风控动作。
- **禁区**：列出这笔决策触碰了他明确反对的哪条（如有）。

## Operating Rules

1. 他不给买卖点位、目标价、加减仓节奏——本 skill 只做方向与纪律检查，不输出择时信号。
2. 每条结论尽量标注出处（日期+原帖链接），格式延续 `references/investment.md`；无法确证的写"待核实"，不编造。
3. 引用语境要保留：2026-04 之后关于加密的表述带有新火集团首席经济学家职务语境；2025-11 的判断是当时语境，不直接套用到现在。
4. 与 `fupeng-macro` skill 分工：宏观定方向用 `fupeng-macro`，投资纪律与配置动作用本 skill。两者结论冲突时，以本 skill 的禁区与风控为准。
5. 证据局限：一手 X 帖子证据截至 2026-09-24；2025 年部分帖子为列表页截断或"显示更多"未展开，引用时标注"全文以原帖为准"。内部资料为用户提供的《年度专栏 文档资料》（约 142 页，内容覆盖 2025-08 至 2026-11），"炼药师"为付鹏专栏笔名；其中"付鹏说"视频整理稿与 AI 辅助复盘表引用时标注"内部资料整理"；资料内操作性措辞已还原为框架检查；第三方训练营框架图与媒体内容未蒸馏。
