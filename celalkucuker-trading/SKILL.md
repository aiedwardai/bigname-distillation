# Celal Kucuker 技术分析框架

## Purpose

以 Celal Kucuker（@CelalKucuker，加密技术分析师）的公开方法论研判行情：先识别周线/月线级教科书形态，以"突破+支撑回踩成功"为确认条件，用斐波那契扩展、历史涨幅等幅复刻、相对强弱倍数三套方法推演分段多目标，用✅/⌛️路线图跟踪进展。输出层级化、可复核的结构有效性检查结论。

证据基线：2026-03 至 2026-09 的 16 条帖子记录（全部为新闻网站二手引用，未直访 X）；止损逻辑、粉丝数、EIGEN 帖未获取。方法论全文与证据链见 `references/methodology.md`、`references/posts.md`。

## Workflow

1. **大结构识别**：在周线/月线图上找教科书形态——下降通道、下降楔形、杯柄、双底、多年下降趋势线。判据是他的语言："flawless chart, perfect correction"。没有教科书结构 = 没有观点。
2. **突破 + 回踩确认**：突破当日不算信号。检查"支撑是否成功回踩"（"The breakout is here, and the support has been successfully retested."）。无回踩的突破 = 结构未确认；回踩失败 = 结构作废。
3. **三套目标定价**（目标永远是序列，不是单点）：
   - Fib 扩展：1.272 / 1.414 / 1.618 扩展位定分段目标；
   - 等幅复刻：把上一次同结构突破后的涨幅（如 517%、330%）原样投影到当前结构；
   - 相对强弱倍数：XRP/BTC 跑赢 10x/13x（复刻 2024），推导山寨币目标。
4. **条件式宏观锚**：BTC 目标只作为条件式前提（"If you believe Bitcoin will reach 140K…"），不为 BTC 做独立技术分析。分析 BTC 时用他的框架，不套用他的 BTC 数字锚（$140K/$150K/$200K 为 2026 年特定时点口径）。
5. **路线图跟踪**：按✅（已达成）/ ⌛️（待验证）列出目标序列进展；配时间窗口（如 "$10 最现实窗口 2026-12 至 2027-02"）。
6. **纪律检查**：对照 Operating Rules 逐项过一遍，输出结论与"还需观察什么"。

## Output Contract

- 结构状态：识别出的大结构 + 形态完整度（教科书程度）+ 依据
- 确认状态：突破是否发生 / 回踩是否成功 / 结构是否作废（带失效条件）
- 分段目标序列：每段目标 + 所用定价法（Fib 扩展 / 等幅复刻 / 相对倍数）+ ✅/⌛️ 进展
- 条件式锚：若用了 BTC 锚，明确标注"条件式，X 口径为 2026 年帖子"
- 纪律检查清单结果：逐项通过 / 未通过 / 数据缺失
- 明确标注：数据日期、引用帖子日期（或"日期未确认"）、二手引用标注、本次未覆盖的内容

## Operating Rules

1. 先有大结构再有观点：下降通道/下降楔形/杯柄/双底/多年趋势线，无结构不下结论。
2. 突破当日不算数，回踩成功才是确认；"A breakout without a retest leaves structure unconfirmed."
3. 目标永远是序列（分段多目标），单点目标不是他的方法；每段目标必须说明用了哪套定价法。
4. 回踩失败 = 结构作废，不硬撑（如跌破 $0.95 区域则杯柄结构失效）。
5. BTC 口径：他对 BTC 只有条件式宏观锚（$140K/$150K/$200K，2026 年帖子口径），无 BTC 独立图表帖——分析 BTC 时用框架，不引用他的 BTC 数字当结论。
6. 不虚构止损逻辑：证据未覆盖他的止损规则，风控部分以熊猫 skill 等其他工具补齐，并在输出中注明"Celal 框架内无止损证据"。
7. 标注证据口径：二手引用标注出处，帖子日期缺失标注"日期未确认"，2026-09 之后的方法论变化不在本次覆盖范围内。
8. 不输出具体买卖点位建议；所有内容不构成投资建议；输出中文。
