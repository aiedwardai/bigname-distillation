# 大咖蒸馏 bigname-distillation

公开市场分析师方法论蒸馏合集。每个大咖独立一个目录，各有 `SKILL.md` 与一手证据链（`references/`）。

## 目录

| 目录 | 大咖 | 一句话 |
|---|---|---|
| `distillP-btc-analysis/` | Phyrex Ni | BTC 资金流四层框架：资金容量 / 资金身份 / 启动意愿 / 供给弹性 |
| `distillcb-trading-analysis/` | 蛋糕爸爸 @CakeBaBa | 纯K线波段：关键点位触发制、US10Y 流动性总开关、TP1/2/3 分批止盈 |
| `fupeng-macro/` | 付鹏 @fupenglondon | 宏观配置：三齿轮框架、黄金三要素、哑铃型配置 |
| `fupeng-investment/` | 付鹏 @fupenglondon | 投资认知：配置思维、缩圈逻辑、小登/中登/老登分群 |
| `panda-trading-school/` | 熊猫交易学社 @qinxiongmao | 裸K纪律：顺大逆小、只跟随不预测、2%/6% 硬止损 |
| `traderfengge-trading/` | 比特币峰哥 @Traderfengge | 趋势跟随合约：结构+斐波那契定买区、下跌不言底 |

| `celalkucuker-trading/` | Celal Kucuker @CelalKucuker | 大周期形态 + 突破回踩 + 三套目标定价 |

顶层 `SKILL.md` 为路由表（含各框架触发语与适用场景）。

## 安装

```bash
git clone https://github.com/aiedwardai/bigname-distillation.git
# 把需要的子目录拷到你的 skills 目录即可单独使用
```

## 说明

- 只做框架与纪律检查，不输出买卖点位，不构成投资建议。
- 蒸馏只保留公开方法论与指标解读口径，已剔除个人信息与推广内容；证据不足的条目如实标注"未核实"。
- 其中 5 个子目录此前已作为独立仓库发布（distillP-btc-analysis、distillcb-trading-analysis、distillfp-macro、distillfp-investment、panda-trading-school），本仓库为统一合集，后续新增蒸馏只进本仓库。
