# 蛋糕爸爸交易方法论

## Purpose
把 YouTube 财经频道「蛋糕爸爸」（@CakeBaBa，2025-12 至 2026-09 约 1200 期节目蒸馏）的波段交易纪律变成可执行的研判流程。核心是：**只做右侧、只看结构、只设触发条件**——不预测、不抄底、不追高。

完整方法论、策略纪律与证据来源见 `references/methodology.md`；代表视频清单见 `references/videos.md`。

## Workflow
1. **定结构**：画趋势线 / 通道，判断周线级别有无假突破 / 假跌破；识别斐波那契关键回撤位。只看结构，不猜消息。
2. **找分界线**：给出当前多空关键点位（参考他"82811 突破没条件看空"的用法：点位到了才行动，没到就观望）。
3. **查总开关**：看 US10Y（美债 10 年期收益率）走势与位置——他眼中股币最大影响变量；列出临近的 CPI / 议息 / ETF 期权到期等事件。
4. **测情绪**：散户一致性（全网喊抄底 / 全民喊牛市）= 逆向危险信号；反弹先定性为逼空，直到结构反转确认。
5. **定动作**：输出条件式动作清单——若突破 X 则转多 / 若跌破 Y 则转空；冲高不追；TP1 / TP2 / TP3 分批止盈计划；事件前后降仓或观望。

## Output Contract
- 结构结论：当前结构、假突破 / 假跌破风险
- 关键点位：多空分界线、支撑 / 阻力
- 流动性与事件：US10Y 位置、临近宏观事件与日历
- 情绪读数：逆向信号有无
- 动作清单：全部条件式表述（"若…则…"），含分批止盈位与事件风控
- 标注：数据日期、指标时效性、本次未覆盖的指标

## Operating Rules
1. 本框架是波段交易纪律，不是长期配置框架；不输出仓位比例、定投或网格计划。
2. 只做条件式表述，不做确定性预测（"突破才看涨"而不是"会涨"）。
3. 不抄底：左侧接飞刀违反本框架；反弹默认定性为逼空，直到结构反转确认。
4. 阈值带时间戳：US10Y 5% 阈值来自 2026-09 语境；82,811 / 83,000 是 2026-09-21 的 BTC 点位示例，不是通用常量。
5. MVRV、恐贪指数、ETF 资金流净额、央行购金不在他的方法论内，不要硬套。
6. 没有实时数据就说明缺口，不编造指标数值，不用旧数据充数。
7. 输出中文；所有内容不构成投资建议。
