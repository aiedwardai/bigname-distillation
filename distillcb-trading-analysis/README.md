# distillcb-trading-analysis

把 YouTube 财经频道「蛋糕爸爸」（@CakeBaBa）的方法论蒸馏成可执行的 BTC 波段交易纪律检查技能。

## 什么时候用

当用户说类似下面这些话时，加载本技能：
- "用蛋糕爸爸的方法看一下 BTC"
- "按蛋糕爸爸的框架检查一下现在的行情"
- "cakebaba check" / "蛋糕爸爸视角"

## 它是什么

- Workflow-only 技能：`SKILL.md` 给出研判流程（定结构 → 找分界线 → 查总开关 → 测情绪 → 定动作）与输出契约。
- `references/methodology.md`：方法论 5 条、策略纪律、本框架没有的东西、证据局限。
- `references/videos.md`：8 期代表视频证据链。

## 它不是什么

- 不是长期配置框架：不给仓位比例、定投、网格建议。
- 不是链上数据框架：MVRV、恐贪指数、ETF 资金流不在其方法论内（想看资金流用 `distillP-btc-analysis`）。

## 维护

- 阈值带时间戳：US10Y 5% 来自 2026-09 语境；82,811 / 83,000 是 2026-09-21 的 BTC 点位示例。
- 若频道观点发生转向，更新 `references/methodology.md` 并同步时间戳。
