# 熊猫交易学社交易方法论

## Purpose
把 YouTube 中文交易教学频道「熊猫交易学社」（@qinxiongmao，熊猫教练；约 2021 年开播，主编号系列截至 2026-09-26 已至第 293 期，约 380–450 条节目；20 条视频证据链见 `references/videos.md`）的价格行为/裸K交易体系变成可执行的研判与纪律检查流程。核心是：**顺大逆小（大周期站方向、小周期等回调顺大入场）；技术分析只为应对不为预测；以损定仓、单笔 2% / 当日 6% 硬止损线**。

完整方法论、纪律清单与口径说明见 `references/methodology.md`；代表视频清单见 `references/videos.md`。

## Workflow
1. **定周期**：先定趋势/利润周期（准备赚哪一段）再定交易周期（约为利润周期向下四倍）；读图四问——这段趋势是哪个级别的？动能怎么样？有没有到末期？趋势级别和我的利润周期是否匹配？
2. **站方向（顺大）**：在大周期上判断主要方向并站队；用"顺强逆弱"过滤——大级别动能打分不强（"好大哥"不在）则直接观望。画出"走势全景地图"：各周期方向/级别/防守位、最大概率的两个剧本、下一个目标、剩余利润空间。
3. **等入场（逆小）**：在小周期等待与大方向相反的回调走完，出现有效信号K线（顺应趋势＋落在关键支撑/阻力位＋有确认）或二次突破（低二/高二）再入场；信号出现可先小仓位小止损验证。不追单，不做系统外单子。
4. **设三要素**：入场前先定防守位（逻辑失效的确认点，破位则剧本失效重判）与时间止损；止损位置由市场结构决定，再以"以损定仓"（仓位＝可承受风险金额÷止损比例）算仓位；T1 目标看前高/前低，"不赚最后一个铜板"。
5. **纪律检查**：单笔亏损是否超账户 2%？当日亏损＋持仓风险是否到 6% 线（到线停手）？持仓周期是否仍由开仓前计划决定（警惕"把短线做成长线"）？是否在"上头"后连续交易？T1 短线单是否动了订单管理？

## Output Contract
- 周期与方向：趋势/利润周期、交易周期、当前大周期方向与动能评分、顺强逆弱是否满足
- 剧本与防守位：最大概率的两个剧本、各自的防守位（破位即剧本失效）、时间止损条件
- 入场条件：顺大逆小的入场形态（信号K线/二次突破/SB结构）、关键位置要求，全部条件式表述（"若…则…"）
- 三要素：入场 / 止损 / 止盈（T1 看前高/前低），附以损定仓的仓位推导
- 纪律检查：2%/6% 线、上头/追单/临时改计划/短线长做等反对清单对照
- 标注：数据与阈值的时间戳、哪些结论引自其自述（未经验证）、本次未覆盖的指标

## Operating Rules
1. 只做条件式表述与趋势跟随，不做确定性买卖点位："若价格回到 X 且出现有效信号K线，则按剧本 A 入场"，而不是"在 X 买入"。
2. 阈值带时间戳：单笔 2% / 当日 6% / 以损定仓公式是其 2025-05 第 224 期视频中的表述；引用时注明出处与日期，不当作普适常量。
3. 其自述的战绩、胜率（如标题中的"90%胜率""高胜率买点"）必须标注为自述、未经独立验证；不得把标题营销语写成验证过的事实。
4. 其月度/周度市场展望的具体研判内容未能获取：**不得编造他曾"预测对某行情"的案例**，也不得反向推定市场走势等于他的研判。
5. 左侧/右侧立场、假突破 7 种方法、支撑压力具体找法、成交量口诀、缠论具体用法等未能核实的内容：分析中不得脑补为他的原话；可用"顺大逆小"框架做方向性推演，但须注明是推演而非其原话。
6. 资金流/链上维度（ETF 资金流、MVRV、稳定币等）不在他的方法论内，不要硬套；想看资金流用 `distillP-btc-analysis`，想看链上数据用 `web3trading`。
7. 宏观框架与大类资产配置检查用 `fupeng-macro` / `fupeng-investment`；纯 K 线波段纪律检查用 `distillcb-trading-analysis`；本 skill 负责"多周期结构＋入场信号＋纪律风控"这一层。
8. 输出中文；所有内容不构成投资建议（与其频道声明一致：内容仅代表方法论蒸馏，"有可能全是错的"）。
