# panda-trading-school

蒸馏 YouTube 中文交易教学频道「熊猫交易学社」（@qinxiongmao，熊猫教练）的价格行为 / 裸K 交易方法论，形成可执行的研判与纪律检查流程。

- **SKILL.md**：方法论研判流程（顺大逆小、信号K线入场、以损定仓、防守位剧本管理）
- **references/methodology.md**：全文蒸馏（人物与频道、核心理念、市场框架、交易系统、庄家思维、风险管理与纪律、明确反对做法、适用边界）
- **references/videos.md**：20 条代表视频证据链（口径分层标注）

核心：**顺大逆小**（大周期站方向、小周期等反向回调后顺大入场）；**技术分析只为应对不为预测**；**以损定仓、单笔 2% / 当日 6% 硬止损线**。

蒸馏日期 2026-09-26。口径：■= 公开页面/逐字转写可验证（一手）；▲= 学员转述/第三方摘要（二手）；△= 未能核实（已单独列出）。其自述战绩、胜率一律标注"（自述，未经独立验证）"。

内容仅为方法论蒸馏，不构成投资建议。
