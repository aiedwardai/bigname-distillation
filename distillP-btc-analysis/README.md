# distillP-btc-analysis

一套 BTC 资金流四层分析框架的 AI Skill：资金容量 → 资金身份 → 启动意愿 → 供给弹性，用于研判 BTC 牛熊状态、寻找底部线索、评估抛压量级。

> 方法论蒸馏自某中文加密数据分析师的公开内容（已去除个人信息、推广链接与个人财务细节，仅保留框架、指标与解读口径）。所有内容不构成投资建议。

## 结构

```
SKILL.md                      # 框架工作流、输出格式、操作规则
references/indicators.md      # 16 个指标明细：用途、解读口径、时效性标注
```

## 核心框架

1. **资金容量**：稳定币总市值（购买力上限）、BTC 现货 ETF 总持仓——场内有多少钱能买？
2. **资金身份**：稳定币币种分拆、ETF 发行商分拆（BlackRock / 灰度 / 其他）、波动时区归因——是谁的钱？增量还是存量？
3. **启动意愿**：宏观政策变量（美联储、CPI、非农、日央行与套息）、VIX 阈值、ETF 流量与情绪背离——钱愿不愿意进场？
4. **供给弹性**：长期持有者供给、成本区间筹码、灰度系抛售占初始持仓比例——有多少筹码会卖？

## 方法特征

- 连续观察，不以单日下结论；ETF 流量用 BTC 枚数口径
- 分拆优于总量（稳定币分币种、ETF 分发行商）
- 资金流 × 价格 × 情绪交叉验证；筹码密集区只做参考位，不做方向担保
- ETF 二级市场交易的是份额不是 BTC，份额波动 ≠ 底层 BTC 买卖

## 使用

将 `SKILL.md` 作为 skill 加载到你的 AI 助手（Claude Code / Muse / 其他支持 skill 的 Agent 环境），说"用这个框架分析一下 BTC 当前行情"即可触发。
